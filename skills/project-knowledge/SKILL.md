# プロジェクト固有知識の参照手順

このファイルは共有テンプレートが管理する **読み込み手順だけ** を書く。知識本文は利用側リポジトリが `references/` 配下で管理する。

## 手順

1. `references/index.md`（この SKILL.md と同じディレクトリ配下）を読む
   - 存在しない場合は「プロジェクト固有の知識は未登録」として、この Skill の処理を終えて通常どおり作業を続ける
2. 索引の各行の「読む条件」と現在のタスク（エラーメッセージ・対象ディレクトリ・作業種別）を照合する
3. 条件に合う参照ファイル **だけ** を読む
   - 該当なしなら何も読まない。索引の全ファイルを一括で読まない
   - 候補が多い場合は、エラーメッセージや対象パスで `Grep` して該当箇所に絞ってから読む
4. 読んだ内容を作業に使う。どの参照を読んだか（または読まなかったか）を 1 行で報告する

## 書き込みについて

- この Skill は参照専用。作業中に自動で `references/` へ追記しない
- 新しい知見を残す場合は、ユーザーに確認したうえで `templates/` の書式に沿って利用側リポジトリで追加する
- 共有テンプレート側（`SKILL.md` / `templates/`）には個別プロジェクトの事例を書かない
