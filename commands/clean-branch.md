マージ済みのローカルブランチを整理（削除）する。

## 手順

1. ベースブランチを特定する（優先順: `develop` → `main`。リポジトリに存在するものを使う）
2. ベースブランチに `git switch` で移動する（既にそのブランチにいる場合はスキップ。未コミット変更があって移動できなければ停止して報告する）
3. `git fetch --prune` でリモートの最新状態を取得し、削除済みリモートブランチの追跡を除去する
4. `git branch --merged origin/<base>` でベースに取り込まれたローカルブランチ一覧を取得する（`main` / `develop` および現在チェックアウト中のブランチは除外）
5. `git worktree list` で他の worktree が使っているブランチを除外する
6. 残ったブランチを `git branch -d <branch>` で削除する
7. 削除したブランチと、除外したブランチ（理由付き）を表示する

## ルール

- `main` / `develop` ブランチは絶対に削除しない
- 現在チェックアウト中のブランチ、他の worktree で使われているブランチは削除対象から除外する
- 統合済みブランチのみを対象とする（`-d` を使い、`-D` は使わない）。`-d` が未統合として拒否したブランチは削除せず、一覧に残して報告する
- squash / rebase で統合されたため `--merged` に出ないブランチは、自動では削除しない（対応する PR が merge 済みか確認したうえで利用者に判断を求める）
- リモートブランチは削除しない
- 判断基準: `.claude/scripts/git-guard.md`
